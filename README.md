# 💎 BhojanPatri

**The Most Reliable & High-Performance Restaurant OS for the Modern Era.**

BhojanPatri is a premium, ultra-lightweight self-ordering and food management ecosystem designed to scale restaurant operations from a single outlet to national franchise chains. Engineered for high-volume environments where every second counts.

![BhojanPatri Banner](/banner.png)

---

## ✨ Core Ecosystem

- **⚡ Zero-Install PWA**: No heavy apps. Works instantly in any mobile browser (Chrome, Safari, etc.).
- **📱 Any-Device Sync**: Flawless performance on budget Androids, iPhones, tablets, and desktops.
- **🛠️ Command Center**: Real-time order management, analytics, and staff control from one dashboard.
- **📦 Smart Inventory**: Stock consumption tracking with low-stock alerts and recipe mapping.
- **🎨 Premium UI/UX**: Immersive glassmorphism design with smooth micro-animations and dual-theme support.
- **🧾 Enterprise Billing**: High-speed offline-first billing with GST, service charges, and discount logic.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/), [Vite](https://vitejs.dev/), [Tailwind CSS 4](https://tailwindcss.com/)
- **Backend**: [Firebase Firestore](https://firebase.google.com/docs/firestore), [Firebase Auth](https://firebase.google.com/docs/auth)
- **Architecture**: Real-time synchronization, PWA (Manifest supported), Mobile-first design.

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/manas0x/BhojanPatri.git
   cd BhojanPatri
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Firebase**
   Update your credentials in `src/firebase.js`.

4. **Launch Development Server**
   ```bash
   npm run dev
   ```

5. **Build for Production**
   ```bash
   npm run build
   ```
