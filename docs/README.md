# BhojanPatri Documentation

BhojanPatri is a premium self-ordering and food management system designed to scale restaurant operations and enhance customer dining experiences.

## Key Features

- **Smart QR Ordering**: Customers can scan table-specific QR codes to access the menu and place orders.
- **Real-time Order Management**: Admins receive and manage orders in real-time through an intuitive dashboard.
- **Digital Menu**: Easy-to-manage digital menu with category filtering and availability toggles.
- **Dual Themes**: Supports both light and dark modes for optimal viewing in any environment.
- **Analytics & History**: Track customer profiles and order history to understand business performance.

## Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS 4
- **Backend**: Firebase Firestore, Firebase Auth
- **PWA**: Manifest support for a native-like mobile experience

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Configure your Firebase settings in `src/firebase.js`.
4. Run development server: `npm run dev`
5. Build for production: `npm run build`
